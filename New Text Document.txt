### Step 1: Low-Power Wake Word (`react-native-vosk`)
We will use `react-native-vosk` in **grammar mode** to listen only for "hey assistant", keeping CPU usage under 2%.

**1. Install & Prebuild**
```bash
npx expo install react-native-vosk
npx expo prebuild -p android # Creates the native android directory
```

**2. Wake Word Hook (React Native)**
Download the `vosk-model-small-en-us-0.15` and place it in `android/app/src/main/assets/vosk-model`.

```javascript
import Vosk, { Recognizer } from 'react-native-vosk';
import { useEffect, useState } from 'react';

export const useWakeWord = (onWakeDetected) => {
  const [isListening, setIsListening] = useState(false);

  useEffect(() => {
    const setupVosk = async () => {
      await Vosk.loadModel();
      // Grammar mode: ONLY listen for this phrase to save massive battery
      const recognizer = new Recognizer(['hey assistant', 'hey assistant hey assistant']);
      
      Vosk.addListener((result) => {
        if (result && result.text.includes('hey assistant')) {
          onWakeDetected();
          recognizer.reset(); // Reset to catch the actual user command next
        }
      });

      Vosk.startRecognizing(recognizer);
      setIsListening(true);
    };

    setupVosk();
    return () => {
      Vosk.stopRecognizing();
      setIsListening(false);
    };
  }, []);

  return isListening;
};
```

### Step 2: Gemini Real-Time API (WebSocket Streaming)
The Gemini Real-Time API uses bidirectional WebSockets, which is perfect for streaming audio chunks from React Native and getting back text or tool calls instantly.

```javascript
import { useRef, useEffect } from 'react';

const GEMINI_WS_URL = `wss://generativelanguage.googleapis.com/ws/google.ai.generativelanguage.v1alpha.GenerativeService.BidiGenerateContent?key=YOUR_API_KEY`;

export const useGeminiRealtime = () => {
  const wsRef = useRef(null);

  useEffect(() => {
    wsRef.current = new WebSocket(GEMINI_WS_URL);

    wsRef.current.onopen = () => {
      console.log('✅ Gemini Real-Time Connected');
      // Send initial setup message if required by your specific tool configuration
    };

    wsRef.current.onmessage = (event) => {
      const response = JSON.parse(event.data);
      // Handle Gemini's response (text, tool calls, etc.)
      if (response.candidates) {
        console.log('Gemini says:', response.candidates[0].content.parts[0].text);
      }
    };

    return () => wsRef.current?.close();
  }, []);

  const sendAudioChunk = (base64Audio) => {
    if (wsRef.current?.readyState === WebSocket.OPEN) {
      wsRef.current.send(JSON.stringify({
        realtime_input: {
          media_chunks: [{
            mime_type: "audio/pcm",
            data: base64Audio
          }]
        }
      }));
    }
  };

  return { sendAudioChunk };
};
```
*(Note: Pair this with `expo-av` or `react-native-audio-recorder-player` to capture PCM audio chunks and feed them to `sendAudioChunk`).*

### Step 3: On-Screen Awareness (MediaProjection)
Expo doesn’t have a built-in MediaProjection module. You will need to create a **Custom Native Module** to capture the screen and pass the image URI to React Native, which then sends it to Gemini Vision.

**1. Create Native Module (`android/app/src/main/java/com/yourapp/ScreenCaptureModule.kt`)**
```kotlin
package com.yourapp

import android.app.Activity
import android.content.Context
import android.content.Intent
import android.media.projection.MediaProjectionManager
import com.facebook.react.bridge.*

class ScreenCaptureModule(reactContext: ReactApplicationContext) : ReactContextBaseJavaModule(reactContext) {
    override fun getName() = "ScreenCaptureModule"

    @ReactMethod
    fun startCapture(promise: Promise) {
        val activity = currentActivity ?: return promise.reject("NO_ACTIVITY", "No activity found")
        val mediaProjectionManager = activity.getSystemService(Context.MEDIA_PROJECTION_SERVICE) as MediaProjectionManager
        
        // This triggers the Android system permission dialog
        val intent = mediaProjectionManager.createScreenCaptureIntent()
        activity.startActivityForResult(intent, 1001) // Handle result in MainActivity
        promise.resolve("Permission requested")
    }
}
```
**2. React Native Usage**
Once the screen is captured (saved as a temporary JPEG/PNG via the native module), read the file using `expo-file-system` and send it to Gemini:
```javascript
import * as FileSystem from 'expo-file-system';

const analyzeScreen = async (imageUri) => {

      contents: [{
        parts: [
          { text: "What is currently on this screen? Summarize it." },

        ]
      }]
    })

  const data = await response.json();

};
```

### Step 5: Shazam Integration (The Expo-Friendly Way)
Running Python (`ShazamIO`) directly inside an Expo app is highly discouraged (requires complex native bridges like Chaquopy). 

**The Best Practice Architecture:**
1. React Native records 5 seconds of audio using `expo-av` (`Audio.Recording`).
2. RN uploads the `.wav` file to **your own lightweight backend** (e.g., a $5/mo VPS running Python/FastAPI).
3. Your backend runs `ShazamIO`, gets the track metadata, and returns it to React Native.

**Backend Example (Python FastAPI + ShazamIO):**
```python
from fastapi import FastAPI, UploadFile
from shazamio import Shazam
import shutil

app = FastAPI()
shazam = Shazam()

@app.post("/identify")
async def identify_audio(file: UploadFile):
    temp_path = "temp_audio.wav"
    with open(temp_path, "wb") as buffer:
        shutil.copyfileobj(file.file, buffer)
    
    result = await shazam.recognize(temp_path)
    if "track" in result:
        return {"title": result["track"]["title"], "artist": result["track"]["subtitle"]}
    return {"error": "No match found"}
```

### 1. The Core Service: `MyAccessibilityService.kt`
This is the actual Android service that runs in the background. It holds a static reference to itself so our React Native bridge can trigger actions.

**Path:** `android/app/src/main/java/com/yourapp/MyAccessibilityService.kt`

```kotlin
package com.yourapp

import android.accessibilityservice.AccessibilityService
import android.accessibilityservice.GestureDescription
import android.graphics.Path
import android.util.Log
import android.view.accessibility.AccessibilityEvent

class MyAccessibilityService : AccessibilityService() {

    companion object {
        // Static instance so the React Native bridge can access it
        var instance: MyAccessibilityService? = null
            private set
    }

    override fun onServiceConnected() {
        super.onServiceConnected()
        instance = this
        Log.d("AccessibilityService", "✅ Service Connected and Ready")
    }

    override fun onAccessibilityEvent(event: AccessibilityEvent?) {
        // We don't need to react to every UI event for this boilerplate, 
        // but you can listen for specific app opens or text changes here.
    }

    override fun onInterrupt() {
        Log.w("AccessibilityService", "⚠️ Service Interrupted")
    }

    override fun onDestroy() {
        super.onDestroy()
        instance = null
        Log.d("AccessibilityService", "❌ Service Destroyed")
    }

    // --- ACTION METHODS CALLED BY REACT NATIVE ---

    fun performGlobalAction(action: Int): Boolean {
        return performGlobalAction(action) // Built-in Android method
    }

    fun performTap(x: Float, y: Float, callback: (Boolean) -> Unit) {
        val path = Path().apply { moveTo(x, y) }
        val stroke = GestureDescription.StrokeDescription(path, 0, 100) // 100ms duration
        val gesture = GestureDescription.Builder().addStroke(stroke).build()

        dispatchGesture(gesture, object : GestureResultCallback() {
            override fun onCompleted(gestureDescription: GestureDescription?) {
                callback(true)
            }
            override fun onCancelled(gestureDescription: GestureDescription?) {
                callback(false)
            }
        }, null)
    }

    fun performSwipe(startX: Float, startY: Float, endX: Float, endY: Float, durationMs: Long, callback: (Boolean) -> Unit) {
        val path = Path().apply {
            moveTo(startX, startY)
            lineTo(endX, endY)
        }
        val stroke = GestureDescription.StrokeDescription(path, 0, durationMs)
        val gesture = GestureDescription.Builder().addStroke(stroke).build()

        dispatchGesture(gesture, object : GestureResultCallback() {
            override fun onCompleted(gestureDescription: GestureDescription?) {
                callback(true)
            }
            override fun onCancelled(gestureDescription: GestureDescription?) {
                callback(false)
            }
        }, null)
    }
}
```

### 2. The React Native Bridge: `AccessibilityBridgeModule.kt`
This module exposes the Kotlin functions to JavaScript so you can call them like normal async functions in React Native.

**Path:** `android/app/src/main/java/com/yourapp/AccessibilityBridgeModule.kt`

```kotlin
package com.yourapp

import android.accessibilityservice.AccessibilityService
import com.facebook.react.bridge.*

class AccessibilityBridgeModule(reactContext: ReactApplicationContext) : ReactContextBaseJavaModule(reactContext) {

    override fun getName(): String = "AccessibilityBridge"

    @ReactMethod
    fun isServiceEnabled(promise: Promise) {
        promise.resolve(MyAccessibilityService.instance != null)
    }

    @ReactMethod
    fun goBack() {
        val service = MyAccessibilityService.instance
        if (service != null) {
            service.performGlobalAction(AccessibilityService.GLOBAL_ACTION_BACK)
        } else {
            throw Exceptions.ReactMethodNotFoundException("Accessibility Service not running")
        }
    }

    @ReactMethod
    fun goHome() {
        val service = MyAccessibilityService.instance
        if (service != null) {
            service.performGlobalAction(AccessibilityService.GLOBAL_ACTION_HOME)
        }
    }

    @ReactMethod
    fun tap(x: Float, y: Float, promise: Promise) {
        val service = MyAccessibilityService.instance
        if (service == null) {
            promise.reject("NO_SERVICE", "Accessibility Service is not enabled in Settings")
            return
        }

        service.performTap(x, y) { success ->
            if (success) promise.resolve("Tap successful")
            else promise.reject("TAP_FAILED", "System cancelled the tap")
        }
    }

    @ReactMethod
    fun swipe(startX: Float, startY: Float, endX: Float, endY: Float, durationMs: Int, promise: Promise) {
        val service = MyAccessibilityService.instance
        if (service == null) {
            promise.reject("NO_SERVICE", "Accessibility Service is not enabled in Settings")
            return
        }

        service.performSwipe(startX, startY, endX, endY, durationMs.toLong()) { success ->
            if (success) promise.resolve("Swipe successful")
            else promise.reject("SWIPE_FAILED", "System cancelled the swipe")
        }
    }
}
```
*Note: Don't forget to register this module in your `MainApplication.kt` inside the `getPackages()` method by adding `AccessibilityBridgeModule(reactApplicationContext)` to the list.*

### 🚨 Crucial Testing Step for Android
When you build and run this app, **it will not work immediately**. Android requires the user to manually toggle the service on for security reasons.

1. Open your app.
2. Call `checkAccessibilityEnabled()`. It will return `false`.
3. Call `promptUserToEnableAccessibility()`.
4. The user goes to **Settings > Accessibility > [Your App Name] > AI Assistant Controller** and turns the toggle **ON**.
5. Android will show a scary warning ("This service can read all your screen text..."). The user must accept.
6. Now, `aiTap(500, 1000)` will actually tap the screen!

### Step 2: The Python Script
Place this in the default Chaquopy source directory: `android/app/src/main/python/shazam_recognizer.py`

```python
import asyncio
import json
from shazamio import Shazam

def recognize_song(file_path: str) -> str:
    """
    Synchronous wrapper for async ShazamIO.
    Returns a JSON string to be easily parsed by Kotlin/React Native.
    """
    async def _recognize():
        shazam = Shazam()
        try:
            out = await shazam.recognize(file_path)
            if 'track' in out:
                track = out['track']
                # Extract safe fallbacks for missing data
                hub = track.get('hub', {})
                actions = hub.get('actions', [{}])
                providers = hub.get('providers', [{}])
                
                return json.dumps({
                    "success": True,
                    "title": track.get('title', 'Unknown Title'),
                    "artist": track.get('subtitle', 'Unknown Artist'),
                    "apple_music": actions[0].get('uri', '') if actions else '',
                    "spotify": providers[0].get('actions', [{}])[0].get('uri', '') if providers else ''
                })
            else:
                return json.dumps({"success": False, "error": "No match found"})
        except Exception as e:
            return json.dumps({"success": False, "error": str(e)})

    # Run the async function in the current thread
    return asyncio.run(_recognize())
```

### Step 3: The Kotlin Bridge Module (Documentation Compliant)
This module safely checks if Python is started, converts the React Native `file://` URI to a native Android path, and returns the JSON string.

**Path:** `android/app/src/main/java/com/yourapp/ShazamModule.kt`

```kotlin
package com.yourapp

import android.net.Uri
import com.chaquo.python.Python
import com.chaquo.python.android.AndroidPlatform
import com.facebook.react.bridge.*

class ShazamModule(reactContext: ReactApplicationContext) : ReactContextBaseJavaModule(reactContext) {

    override fun getName(): String = "ShazamModule"

    private fun ensurePythonInitialized() {
        // Official Chaquopy recommendation for conditional initialization
        if (!Python.isStarted()) {
            Python.start(AndroidPlatform(reactApplicationContext))
        }
    }

    @ReactMethod
    fun identifySong(audioFileUri: String, promise: Promise) {
        try {
            ensurePythonInitialized()
            
            // Convert React Native "file:///..." URI to a native Android absolute path
            val uri = Uri.parse(audioFileUri)
            val filePath = uri.path 
            if (filePath == null || java.io.File(filePath).exists().not()) {
                promise.reject("FILE_NOT_FOUND", "Audio file does not exist at: $audioFileUri")
                return
            }

            // Import the Python module and call the function
            val shazamModule = Python.getInstance().getModule("shazam_recognizer")
            val resultJson = shazamModule.callAttr("recognize_song", filePath).toString()
            
            // Return the JSON string directly to JavaScript
            promise.resolve(resultJson)

        } catch (e: Exception) {
            promise.reject("SHAZAM_ERROR", e.message ?: "Unknown Python error")
        }
    }
}
```

```javascript
import { NativeModules, Platform } from 'react-native';
import { Audio } from 'expo-av';

const { ShazamModule } = NativeModules;

export const identifyCurrentSong = async () => {
  if (Platform.OS !== 'android') {
    throw new Error('Chaquopy ShazamIO is currently Android-only.');
  }

  try {
    // 1. Request permissions
    const { status } = await Audio.requestPermissionsAsync();
    if (status !== 'granted') {
      throw new Error('Microphone permission is required');
    }

    // 2. Set up audio recording
    await Audio.setAudioModeAsync({
      allowsRecordingIOS: true,
      playsInSilentModeIOS: true,
    });

    const recording = new Audio.Recording();
    await recording.prepareToRecordAsync({
      android: {
        extension: '.wav',
        outputFormat: Audio.RECORDING_OPTION_ANDROID_OUTPUT_FORMAT_DEFAULT,
        audioEncoder: Audio.RECORDING_OPTION_ANDROID_AUDIO_ENCODER_DEFAULT,
        sampleRate: 44100,
        numberOfChannels: 1,
        bitRate: 128000,
      },
    });

    console.log('🎤 Listening for 5 seconds...');
    await recording.startAsync();

    // Wait 5 seconds
    await new Promise(resolve => setTimeout(resolve, 5000));

    await recording.stopAndUnloadAsync();
    const uri = recording.getURI(); // Returns something like "file:///data/user/0/..."
    console.log('✅ Recording saved to:', uri);

    // 3. Send to Chaquopy Python module
    console.log('🐍 Sending to ShazamIO via Chaquopy...');
    const resultJson = await ShazamModule.identifySong(uri);
    const result = JSON.parse(resultJson);

    if (result.success) {
      console.log(`🎵 Found: ${result.title} by ${result.artist}`);
      return result;
    } else {
      console.log('❌ No match found:', result.error);
      return null;
    }

  } catch (error) {
    console.error('Shazam Identification Failed:', error);
    throw error;
  }
```

```javascript
const {
  withAppBuildGradle,
  withProjectBuildGradle,
  withMainApplication,
  withDangerousMod,
} = require('@expo/config-plugins');
const path = require('path');
const fs = require('fs');

const withChaquopyShazam = (config) => {
  const packageName = config.android?.package || 'com.yourapp';
  const packagePath = packageName.replace(/\./g, '/');

  // 1. Modify Project-level build.gradle
  config = withProjectBuildGradle(config, (config) => {
    let buildGradle = config.modResults.contents;
    
    if (!buildGradle.includes('chaquo.com/maven')) {
      buildGradle = buildGradle.replace(
        /(repositories\s*\{)/,
        '$1\n        maven { url "https://chaquo.com/maven" }'
      );
    }
    
    if (!buildGradle.includes('com.chaquo.python:gradle')) {
      buildGradle = buildGradle.replace(
        /(dependencies\s*\{)/,
        '$1\n        classpath "com.chaquo.python:gradle:17.0.0"'
      );
    }
    
    config.modResults.contents = buildGradle;
    return config;
  });

  // 2. Modify App-level build.gradle
  config = withAppBuildGradle(config, (config) => {
    let appBuildGradle = config.modResults.contents;

    if (!appBuildGradle.includes('id "com.chaquo.python"')) {
      appBuildGradle = appBuildGradle.replace(
        /(plugins\s*\{)/,
        '$1\n    id "com.chaquo.python"'
      );
    }

    if (!appBuildGradle.includes('abiFilters')) {
      appBuildGradle = appBuildGradle.replace(
        /(defaultConfig\s*\{)/,
        '$1\n        ndk {\n            abiFilters += listOf("arm64-v8a", "x86_64")\n        }'
      );
    }

    if (!appBuildGradle.includes('chaquopy {')) {
      appBuildGradle += `\nchaquopy {\n    defaultConfig {\n        version = "3.11"\n        pip {\n            install "shazamio"\n            install "numpy"\n        }\n    }\n}\n`;
    }

    config.modResults.contents = appBuildGradle;
    return config;
  });

  // 3. Modify MainApplication.kt to register the module
  config = withMainApplication(config, (config) => {
    let mainApp = config.modResults.contents;
    const importStatement = `import ${packageName}.ShazamModule`;
    const addStatement = `packages.add(ShazamModule(reactApplicationContext))`;

    if (!mainApp.includes(importStatement)) {
      const importRegex = /(import\s+[\w\.]+\s*\n)/g;
      const matches = [...mainApp.matchAll(importRegex)];
      if (matches.length > 0) {
        const lastImport = matches[matches.length - 1];
        mainApp = mainApp.slice(0, lastImport.index + lastImport[0].length) + 
                  `${importStatement}\n` + 
                  mainApp.slice(lastImport.index + lastImport[0].length);
      }
    }

    if (!mainApp.includes(addStatement)) {
      mainApp = mainApp.replace(
        /(override fun getPackages\(\): List<ReactPackage>\s*\{)/,
        `$1\n        ${addStatement}`
      );
    }

    config.modResults.contents = mainApp;
    return config;
  });

  // 4. Write Python and Kotlin files directly to the Android project
  config = withDangerousMod(config, [
    'android',
    async (config) => {
      const androidDir = config.modRequest.platformProjectRoot;
      
      // Write Python script
      const pythonDir = path.join(androidDir, 'app/src/main/python');
      if (!fs.existsSync(pythonDir)) {
        fs.mkdirSync(pythonDir, { recursive: true });
      }
      
      const pythonCode = `import asyncio
import json
from shazamio import Shazam

def recognize_song(file_path: str) -> str:
    async def _recognize():
        shazam = Shazam()
        try:
            out = await shazam.recognize(file_path)
            if 'track' in out:
                track = out['track']
                hub = track.get('hub', {})
                actions = hub.get('actions', [{}])
                providers = hub.get('providers', [{}])
                
                return json.dumps({
                    "success": True,
                    "title": track.get('title', 'Unknown Title'),
                    "artist": track.get('subtitle', 'Unknown Artist'),
                    "apple_music": actions[0].get('uri', '') if actions else '',
                    "spotify": providers[0].get('actions', [{}])[0].get('uri', '') if providers else ''
                })
            else:
                return json.dumps({"success": False, "error": "No match found"})
        except Exception as e:
            return json.dumps({"success": False, "error": str(e)})

    return asyncio.run(_recognize())`;
      
      fs.writeFileSync(path.join(pythonDir, 'shazam_recognizer.py'), pythonCode);

      // Write Kotlin bridge module
      const kotlinDir = path.join(androidDir, `app/src/main/java/${packagePath}`);
      if (!fs.existsSync(kotlinDir)) {
        fs.mkdirSync(kotlinDir, { recursive: true });
      }

      const kotlinCode = `package ${packageName}

import android.net.Uri
import com.chaquo.python.Python
import com.chaquo.python.android.AndroidPlatform
import com.facebook.react.bridge.*

class ShazamModule(reactContext: ReactApplicationContext) : ReactContextBaseJavaModule(reactContext) {

    override fun getName(): String = "ShazamModule"

    private fun ensurePythonInitialized() {
        if (!Python.isStarted()) {
            Python.start(AndroidPlatform(reactApplicationContext))
        }
    }

    @ReactMethod
    fun identifySong(audioFileUri: String, promise: Promise) {
        try {
            ensurePythonInitialized()
            
            val uri = Uri.parse(audioFileUri)
            val filePath = uri.path 
            if (filePath == null || java.io.File(filePath).exists().not()) {
                promise.reject("FILE_NOT_FOUND", "Audio file does not exist at: $audioFileUri")
                return
            }

            val shazamModule = Python.getInstance().getModule("shazam_recognizer")
            val resultJson = shazamModule.callAttr("recognize_song", filePath).toString()
            
            promise.resolve(resultJson)

        } catch (e: Exception) {
            promise.reject("SHAZAM_ERROR", e.message ?: "Unknown Python error")
        }
    }
}`;

      fs.writeFileSync(path.join(kotlinDir, 'ShazamModule.kt'), kotlinCode);

      return config;
    },
  ]);

  return config;
};
```

### Step 2: The Expo Config Plugin
This plugin handles copying the model into the Android assets directory and injects the required Foreground Service permissions for Android 14+ compatibility.

**Path:** `plugins/withVoskWakeWord.js`
```javascript
const { withAndroidManifest, withDangerousMod } = require('@expo/config-plugins');
const path = require('path');
const fs = require('fs');

const withVoskWakeWord = (config) => {
  // 1. Copy Vosk model from project root to Android assets
  config = withDangerousMod(config, [
    'android',
    async (config) => {
      const projectRoot = config.modRequest.projectRoot;
      const androidDir = config.modRequest.platformProjectRoot;
      
      const sourceModelDir = path.join(projectRoot, 'assets', 'vosk-model');
      const targetModelDir = path.join(androidDir, 'app', 'src', 'main', 'assets', 'vosk-model');

      if (!fs.existsSync(sourceModelDir)) {
        throw new Error(`Vosk model not found at ${sourceModelDir}. Please download the model and place it in the assets directory.`);
      }

      if (fs.existsSync(targetModelDir)) {
        fs.rmSync(targetModelDir, { recursive: true, force: true });
      }
      
      copyDirSync(sourceModelDir, targetModelDir);
      return config;
    },
  ]);

  // 2. Add Foreground Service and Microphone permissions to AndroidManifest
  config = withAndroidManifest(config, (config) => {
    const manifest = config.modResults;
    const usesPermissions = manifest.manifest['uses-permission'] || [];
    
    const requiredPermissions = [
      'android.permission.RECORD_AUDIO',
      'android.permission.FOREGROUND_SERVICE',
      'android.permission.FOREGROUND_SERVICE_MICROPHONE',
      'android.permission.POST_NOTIFICATIONS'
    ];

    requiredPermissions.forEach(perm => {
      if (!usesPermissions.some(p => p.$?.['android:name'] === perm)) {
        usesPermissions.push({ $: { 'android:name': perm } });
      }
    });

    manifest.manifest['uses-permission'] = usesPermissions;
    return config;
  });

  return config;
};

function copyDirSync(src, dest) {
  fs.mkdirSync(dest, { recursive: true });
  const entries = fs.readdirSync(src, { withFileTypes: true });
  for (let entry of entries) {
    const srcPath = path.join(src, entry.name);
    const destPath = path.join(dest, entry.name);
    if (entry.isDirectory()) {
      copyDirSync(srcPath, destPath);
    } else {
      fs.copyFileSync(srcPath, destPath);
    }
  }
}

module.exports = withVoskWakeWord;
```

### Step 4: React Native Wake Word Service
This service encapsulates the Vosk lifecycle, handles the audio stream, and filters the transcriptions for your specific wake words.

**Path:** `src/services/VoskWakeWordService.js`
```javascript
import Vosk from 'react-native-vosk';

class VoskWakeWordService {
  constructor() {
    this.isLoaded = false;
    this.isListening = false;
    this.onWakeWordDetected = null;
    this.recognizer = null;
  }

  async initialize(onWakeWordDetected) {
    if (this.isLoaded) return;
    
    this.onWakeWordDetected = onWakeWordDetected;
    
    // Load the model from the Android assets folder
    await Vosk.loadModel('vosk-model');
    
    this.recognizer = new Vosk.Recognizer();
    
    Vosk.addListener((result) => {
      if (result && result.text) {
        const text = result.text.toLowerCase().trim();
        
        // Filter for the specific wake words
        if (text.includes('hey nova') || text === 'nova') {
          console.log('[Vosk] Wake word detected:', text);
          if (this.onWakeWordDetected) {
            this.onWakeWordDetected();
          }
        }
      }
    });

    this.isLoaded = true;
    console.log('[Vosk] Service initialized successfully.');
  }

  async startListening() {
    if (!this.isLoaded) {
      throw new Error('VoskWakeWordService must be initialized before starting.');
    }
    if (this.isListening) return;

    await Vosk.startRecognizing(this.recognizer);
    this.isListening = true;
    console.log('[Vosk] Listening for wake word...');
  }

  async stopListening() {
    if (!this.isListening) return;
    
    await Vosk.stopRecognizing();
    this.isListening = false;
    console.log('[Vosk] Stopped listening.');
  }

  destroy() {
    this.stopListening();
    if (this.recognizer) {
      this.recognizer.close();
      this.recognizer = null;
    }
    Vosk.removeAllListeners();
    this.isLoaded = false;
    console.log('[Vosk] Service destroyed.');
  }
}

export default new VoskWakeWordService();
```

### Step 6: Integrating the Shazam Color Shift
To change the orb color when Shazam is active, you do not need a new screen. Instead, pass a state variable to the `NovaAssistantScreen` that dictates the orb's color theme.

Update `src/screens/NovaAssistantScreen.js` to accept an `orbTheme` prop:

```javascript
// Inside NovaAssistantScreen.js
const NovaAssistantScreen = ({ visible, onClose, orbTheme = 'standard' }) => {
  // ... existing code
  
  // Update the NovaOrb rendering to pass the colors
  const orbColors = orbTheme === 'shazam' 
    ? { primary: '#FF007A', secondary: '#B026FF' } // Magenta/Purple for Shazam
    : { primary: '#00D4FF', secondary: '#0099FF' }; // Cyan/Blue for Standard

  return (
    // ... existing layout
    <NovaOrb 
      isActive={isListening} 
      primaryColor={orbColors.primary} 
      secondaryColor={orbColors.secondary} 
    />
    // ...
  );
};
```

Then, in your main `App.js`, manage the theme state when triggering Shazam:

```javascript
// In App.js
const [orbTheme, setOrbTheme] = useState('standard');

// When wake word is detected or user taps Shazam:
const triggerShazam = () => {
  setOrbTheme('shazam');
  setIsNovaVisible(true);
  identifyCurrentSong().then(() => {
    setOrbTheme('standard'); // Revert back when done
  });
};

// Pass it to the screen
<NovaAssistantScreen 
  visible={isNovaVisible} 
  onClose={() => setIsNovaVisible(false)} 
  orbTheme={orbTheme} 
/>
```

This approach keeps the UI unified and uses the orb itself as the primary state indicator for the user.
